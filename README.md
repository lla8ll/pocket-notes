# Pocket Notes

تطبيق ملاحظات محلي (local-first) مبني بـ React وTypeScript وVite، بتصميم الورق الأصفر وواجهة كلاسيكية مستوحاة من iPhone. تُحفظ الملاحظات في المتصفح، ولا يلزم مفتاح API أو حساب أو قاعدة بيانات.

الإصدار الحالي وفق `package.json`: **1.0.0**.

## الميزات

- إنشاء الملاحظات وتحريرها، مع حفظ كل تعديل تلقائيًا في المتصفح.
- اشتقاق العنوان من أول سطر غير فارغ، مع دعم العربية والإنجليزية واتجاه الكتابة التلقائي.
- البحث الفوري في العنوان والمحتوى؛ لا تظهر الملاحظات المحذوفة في البحث الرئيسي.
- تثبيت الملاحظات وإلغاء تثبيتها، وترتيب كل مجموعة حسب آخر تعديل.
- سلة `Recently Deleted` لمدة 30 يومًا، مع المدة المتبقية والاستعادة والحذف النهائي بعد التأكيد.
- تنظيف المحذوفات المنتهية عند فتح التطبيق، حتى بعد إغلاقه لأكثر من 30 يومًا.
- مشاركة الملاحظة عبر Web Share API، أو نسخها، أو تحديد النص للنسخ اليدوي عند تعذر الوصول إلى الحافظة.
- حفظ البيانات القديمة دون تغيير مفتاح التخزين، مع رسائل واضحة عند تعذر الحفظ أو تعارض تعديل من تبويب آخر.
- الورق الأصفر المسطر، والخط المحلي، والأزرار والانتقالات، والتصميم المتجاوب.
- ملفات PWA وأيقونات التطبيق، والعمل دون اتصال بعد اكتمال تحميل ملفات التطبيق أول مرة أثناء الاتصال.

## المتطلبات

- Node.js **22.18 أو أحدث** (ملف `.nvmrc` يختار إصدار Node 22 عند استخدام nvm).
- لا يلزم مفتاح API أو حساب أو قاعدة بيانات.

التقنيات المثبتة في المشروع: React **19.1.1**، TypeScript **5.9.2**، Vite **7.3.6**، وخط Patrick Hand المحلي.

## التثبيت والتشغيل

من جذر المستودع:

```sh
npm ci
npm run dev
```

افتح الرابط المحلي الذي يظهر في الطرفية. لا تفتح `index.html` بالنقر المزدوج عبر `file://`؛ شغّله عبر الخادم المحلي أو استضافة HTTPS.

لمعاينة نسخة الإنتاج بعد البناء:

```sh
npm run check
npm run preview
```

| الأمر | النتيجة |
| --- | --- |
| `npm ci` | تثبيت الإصدارات المحددة في `package-lock.json` |
| `npm run dev` | خادم التطوير (Vite) |
| `npm test` | اختبارات منطق الملاحظات والتخزين والمشاركة |
| `npm run build` | فحص TypeScript وبناء الواجهة وملف العمل دون اتصال داخل `dist/` |
| `npm run test:build` | فحص ناتج البناء والمسارات والأيقونات وService Worker (يُنفَّذ بعد البناء) |
| `npm run check` | الاختبارات ثم البناء ثم اختبارات النشر |
| `npm run preview` | معاينة `dist/` عبر خادم محلي |

ينشئ البناء مجلد `dist/` الذي يمكن نشر محتوياته على استضافة ملفات ثابتة. لا يُتتبَّع في Git؛ يعيد workflow بناءه من المصدر، ويتجاهله `.gitignore`. `vite preview` مخصص للمعاينة المحلية.

## الاختبارات

```sh
npm test
npm run check
```

`npm run check` يشغّل اختبارات منطق الملاحظات والتخزين والمشاركة، ثم البناء، ثم اختبارات النشر في `tests/deployment.test.mjs` (المسارات والأيقونات وService Worker). تفاصيل التحقق اليدوي والقيود موثّقة في [docs/VALIDATION.md](docs/VALIDATION.md).

## النشر على GitHub Pages (اختياري)

يُجري workflow الملف `.github/workflows/pages.yml` الاختبارات والبناء عند الدفع إلى `main` أو فتح طلب سحب إليه. **نشر GitHub Pages معطّل افتراضيًا**؛ رفع المصدر وحده لا يفعّله.

لتفعيل النشر عندما تكون Pages متاحة لحسابك ومستودعك:

1. افتح **Settings → Pages → Build and deployment → Source** واختر **GitHub Actions**.
2. افتح **Settings → Secrets and variables → Actions → Variables**، وأنشئ **Repository variable** باسم `ENABLE_PAGES` وقيمة `true`. هذا متغير إعداد عادي، وليس سرًا.
3. افتح **Actions → Check Pocket Notes and optionally deploy Pages → Run workflow** واختر `main`.
4. بعد نجاح مهمة `deploy` سيظهر رابط التطبيق في صفحة التشغيل وفي **Settings → Pages**.

بعد التفعيل تُختبر التحديثات التالية على `main` وتُنشر تلقائيًا؛ طلبات السحب تُختبر دون نشر. لإيقاف النشر في التشغيلات اللاحقة، احذف `ENABLE_PAGES` أو غيّر قيمته إلى `false`. لا يؤدي ذلك إلى إزالة موقع نُشر سابقًا.

مسارات الملفات وملفات PWA نسبية (`base: './'` في `vite.config.ts`)، فتعمل تحت مسار المستودع وكذلك على جذر نطاق مخصص.

## الهوية وأيقونة التطبيق

اسم التطبيق وعنوان الصفحة وmetadata وManifest هو **Pocket Notes**. الشعار الأصلي محفوظ في `assets/branding/pocket-notes-original.png`. الأيقونات الجاهزة موجودة في `public/icons/v2/`، وتعريف PWA في `public/manifest-v2.webmanifest`.

الأيقونات مضمّنة في المصدر؛ **لا تحتاج Python أو Pillow للتشغيل أو البناء أو CI**. لإعادة توليدها عند صيانة الأصول فقط:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install Pillow
.venv/bin/python scripts/generate-icons.py
```

السكربت لا يعدّل الصورة الأصلية ولا يولّد تصميمًا جديدًا.

## البيانات القديمة

مفتاح التخزين هو `classic-pocket-notes:v1`. الملاحظات الشخصية ليست جزءًا من ملفات المشروع؛ يحتفظ بها المتصفح على أصل الموقع (البروتوكول والنطاق والمنفذ). لا توجد مزامنة بين الأجهزة. مسح بيانات الموقع يمسح الملاحظات، والحذف النهائي وانتهاء مدة الاحتفاظ غير قابلين للتراجع. مدة 30 يومًا تُحسب كـ `30 × 24` ساعة وفق ساعة الجهاز.

## التوافق والعمل دون اتصال

يستهدف التطبيق متصفحات حديثة. العمل دون اتصال يتطلب HTTPS أو localhost، وتحميلًا متصلًا مكتملًا أول مرة. الخط والأيقونات محليان ولا يحتاجان خدمة خارجية أثناء الاستخدام. تراخيص المكونات المضمّنة موجودة في `public/licenses/`. هذه النسخة مشروع ويب/PWA ولا تستخدم Capacitor أو Xcode.
