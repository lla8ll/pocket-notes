# سجل تحديثات Pocket Notes

يوثق هذا الملف التغييرات الرئيسية المنشورة في مشروع **Pocket Notes**. التفاصيل الخاصة بكل إصدار موجودة في ملف ملاحظات الإصدار المرتبط به.

## [1.3.0] — 26 سبتمبر 2026

إصدار يضيف مسار تطبيق iOS ومزامنة سحابية اختيارية، مع الحفاظ على العمل المحلي دون اتصال.

- إضافة مشروع iOS كامل عبر Capacitor وملفات Xcode وSwift.
- إضافة مشاركة أصلية عبر iOS، واهتزازات Haptic، ومراقبة حالة الاتصال.
- إضافة تسجيل الدخول وإنشاء الحساب ومزامنة الملاحظات الاختيارية عبر Supabase.
- إضافة دمج يعتمد على آخر تعديل (`updatedAt`) مع دعم التحديثات الفورية عند تفعيل Realtime.
- الحفاظ على التخزين المحلي الأولي عبر IndexedDB، مع الترحيل والرجوع إلى LocalStorage عند الحاجة.
- إضافة إعدادات Supabase ومخطط قاعدة البيانات وسياسات Row Level Security.
- إزالة تحذيرات الاختبارات القابلة للإصلاح وتحديث سلسلة Capacitor إلى نسخة لا تحتوي على الثغرات التي ظهرت في تقرير التدقيق.
- توحيد تشغيل جميع اختبارات TypeScript والتخزين والمزامنة ضمن `npm test`.

**التحقق:** 37 اختبار وحدة ومزامنة ناجحًا، و10 اختبارات بناء ونشر ناجحة، ونتيجة `npm audit --audit-level=moderate` تساوي صفر ثغرات.

راجع [ملاحظات إصدار 1.3.0](RELEASE_NOTES_v1.3.0.md) للتفاصيل وخطوات الترقية.

## [1.2.0] — 24 سبتمبر 2026

- اعتماد IndexedDB كتخزين أساسي للملاحظات.
- إضافة طبقة Repository وخدمة تخزين مع ترحيل تلقائي من التخزين القديم.
- تحسين التعامل مع فشل التخزين والحفظ المتسلسل واسترجاع البيانات.
- توسيع اختبارات التخزين والترحيل وحالات الفشل.

## [1.0.0] — 10 سبتمبر 2026

- إطلاق تطبيق Pocket Notes بواجهة الورق الأصفر.
- إنشاء وتحرير وحذف واستعادة وتثبيت الملاحظات.
- البحث والمشاركة والعمل دون اتصال وملفات PWA والأيقونات الرسمية.
