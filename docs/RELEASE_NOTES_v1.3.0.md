# Pocket Notes v1.3.0

**تاريخ الإصدار:** 26 سبتمبر 2026  
**الالتزام:** [`94fa555`](https://github.com/lla8ll/pocket-notes/commit/94fa555)  
**نوع الإصدار:** إضافة دعم iOS ومزامنة سحابية اختيارية وتحسينات جودة الاعتماديات والاختبارات

## ملخص

يضيف هذا الإصدار مسارًا أصليًا لتطبيق iOS إلى جانب نسخة الويب/PWA الحالية، ويقدم مزامنة اختيارية بين الأجهزة عبر Supabase. يبقى التطبيق **محليًا ويعمل دون اتصال افتراضيًا**؛ لا تظهر واجهة تسجيل الدخول ولا تُفعّل المزامنة السحابية إلا بعد إعداد متغيرات Supabase.

## الجديد

### iOS وCapacitor

- مشروع iOS قابل للفتح والبناء عبر Xcode داخل `ios/`.
- إعداد Capacitor في `capacitor.config.json` وملفات SPM اللازمة.
- مشاركة الملاحظات عبر Share Sheet الأصلي في iOS.
- Haptic feedback للإجراءات المهمة.
- مراقبة الاتصال وإظهار حالة المزامنة.
- سكربت مساعد لبناء IPA على macOS مع Xcode: `build-ipa.sh`.

### المزامنة السحابية الاختيارية

- تسجيل الدخول وإنشاء الحساب عبر Supabase Auth.
- مزامنة ثنائية الاتجاه للملاحظات عند الاتصال.
- دمج الملاحظات بطريقة **آخر تعديل يفوز** باستخدام `updatedAt`.
- دعم تحديثات Realtime بين الأجهزة عند تفعيل جدول `notes` في Realtime.
- سياسات Row Level Security في `supabase/schema.sql` بحيث لا يرى المستخدم إلا ملاحظاته.
- استمرار العمل المحلي الكامل عند غياب إعدادات Supabase.

### التخزين المحلي والتوافق

- الحفاظ على IndexedDB كتخزين أساسي للإصدار الحالي.
- استمرار الترحيل من LocalStorage القديم والرجوع إليه عند تعذر IndexedDB.
- عدم تغيير مفتاح أو صيغة بيانات الملاحظات الحالية؛ لا يلزم إجراء ترحيل يدوي.
- الحفاظ على ميزات البحث والتثبيت وسلة المحذوفات لمدة 30 يومًا والعمل دون اتصال.

### الجودة والاعتماديات

- إدراج جميع اختبارات TypeScript ضمن `npm test`، بما في ذلك اختبارات التخزين ودمج الملاحظات.
- إزالة تحذير Node التجريبي من مخرجات الاختبارات مع إبقاء التحذيرات الأخرى ظاهرة.
- تحديث `@capacitor/cli` إلى `8.4.3` وإزالة سلسلة `xcode/uuid` التي ظهرت في تقرير التدقيق.
- نتيجة `npm audit --audit-level=moderate`: **0 vulnerabilities**.

## خطوات الترقية

### مستخدمو الويب/PWA

لا توجد خطوات مطلوبة. ثبّت الاعتماديات ثم شغّل:

```bash
npm ci
npm run check
```

بيانات الملاحظات المحلية الحالية محفوظة ولا تحتاج إلى تحويل يدوي.

### تفعيل Supabase

1. أنشئ مشروعًا في [Supabase](https://supabase.com).
2. نفّذ `supabase/schema.sql` في SQL Editor.
3. انسخ `.env.example` إلى `.env.local` وأضف `VITE_SUPABASE_URL` و`VITE_SUPABASE_ANON_KEY`.
4. فعّل Email Auth، وفعّل Realtime اختياريًا لجدول `notes`.
5. راجع [CLOUD_SETUP.md](../CLOUD_SETUP.md) للتفاصيل الأمنية وخطوات التشغيل.

> لا تضع مفتاح `service_role` داخل التطبيق أو ملفات البيئة التي تُبنى للواجهة. المفتاح المسموح للعميل هو `anon public key` فقط، مع الاعتماد على RLS لحماية الصفوف.

### بناء iOS

يتطلب البناء الفعلي **macOS وXcode**:

```bash
npm ci
npm run build
npx cap sync ios
npx cap open ios
```

أو استخدم `./build-ipa.sh` بعد ضبط Team والتوقيع داخل Xcode. لا يمكن إنشاء IPA موقّع على Linux.

## ملاحظات وحدود معروفة

- GitHub Pages غير مفعّل تلقائيًا في المستودع؛ رفع الإصدار لا ينشر الموقع العام وحده.
- المزامنة السحابية اختيارية وتتطلب مشروع Supabase وإعداداته؛ بدونها يعمل التطبيق محليًا فقط.
- اختبار Xcode والتوقيع والمشاركة الأصلية على جهاز iPhone فعلي يتطلب بيئة macOS وجهازًا فعليًا، ولم يُنفّذ داخل بيئة Linux.
- مزامنة الملاحظات تعتمد على آخر تعديل لكل ملاحظة؛ لا توجد ميزة دمج نصي داخل محتوى الملاحظة.
