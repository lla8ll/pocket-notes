This page changes only temporary browser methods in the app frame. It does not seed, clear, or replace saved notes. Edit a disposable test note through the app.

Save failures and reload protection

Waiting for app. Unload guard: not checked.
  1. Save a normal edit, then check: defaultPrevented should be false.
  2. Force save failure and edit the note, then check: defaultPrevented should be true.
  3. Restore writes, press Retry inside the app, then check: defaultPrevented should be false.

The check dispatches a synthetic cancelable event; it never reloads the app or opens a native confirmation.

Delayed clipboard completion

Clipboard: original behavior.
  1. Enable deferred clipboard, then open Share Note and press Copy Note in the app.
  2. Cancel the sheet, reopen Share Note, and start another copy.
  3. Resolve the oldest copy: the new sheet must stay open and busy.
  4. Resolve the latest copy: the current sheet should close with Copied feedback.

Mock copies stay in memory and never change the system clipboard.
